# Tran Van Huy — Flutter Developer Portfolio

Static portfolio built with HTML, CSS and vanilla JavaScript.

## Project structure

1. Partner Enterprise Ecosystem — Qdata & Qlib (one project, two sub-apps)
2. E-Library
3. K12 — System Education

Screenshots are included in `assets/` and galleries support thumbnails + fullscreen lightbox.

Open `index.html` directly in a browser or deploy the folder to GitHub Pages, Netlify, Vercel or Cloudflare Pages.
